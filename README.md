# Portable Power Mixer 🥤🔋☀️

**Patent App. No:** 202441017998  
A solar-powered portable mixer designed for off-grid usage.

---

## 📌 Overview
This project focuses on building a portable mixer system powered using solar energy, enabling operation in remote/off-grid locations.

---

## 🎯 Key Features
- Portable and lightweight
- Solar-powered charging / operation
- Off-grid usable design
- Efficient motor control

---

## ⚙️ Main Blocks
- Solar panel + charging module
- Battery storage
- Motor driver + DC motor
- Mechanical mixing unit
